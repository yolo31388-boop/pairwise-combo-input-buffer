# pairwise-combo-input-buffer

玩家在收招硬直里连按轻拳，第三下却打不出来，输入缓冲只存最后一帧的按键；缓冲有效期按帧数算，帧率波动时 60fps 能连、144fps 断；取消窗口用动画时间判断，但动画事件在低帧率下被跳过；同一帧里方向键和攻击键的到达顺序不稳定，搓招时有时出招有时不出；连招分支只按当前动作 id 匹配，浮空和地面共用一套表互相覆盖；网络延迟下客户端提前进入下一段，服务器还在上一段硬直；手柄摇杆抖动被当成重复方向输入，角色原地转圈；UI 获得焦点时攻击键被吞，玩家以为掉输入；输入优先级没定义，防御和攻击同时按下时随机生效；连招失败后没有回退窗口，角色卡在收招姿势。gameplay/combo_input_buffer.py 是核心，tests/test_combo_input_buffer.py 15个红。要修的是：缓冲保存多帧队列；有效期按时间而非帧；动画事件按时间采样；同帧输入按时间戳排序；分支表按姿态分表；服务器权威窗口；摇杆加死区；UI 焦点不吞战斗输入；优先级显式定义；失败回退到待机。

## 运行

```bash
python -m pytest tests -q
```

初始状态：15 个用例失败。修复实现使全部用例通过，不要修改 `tests/` 下的测试。
